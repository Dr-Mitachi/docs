Definițiile termenilor care apar în tot handbook-ul. Dacă întâlnești un cuvânt necunoscut într-o pagină, caută-l aici.

## Pipeline și etape

| Termen | Ce înseamnă |
| --- | --- |
| **Pipeline** | Traseul complet pe care îl parcurge o persoană, de la primul contact până la a deveni pacient (sau până la închiderea ca _Lost_). |
| **Etapă / stagiu** | Un pas din pipeline: Contact → Call Center → Programat → Consultație → Pacient în tratament → Pacient / Lost. |
| **Lead** | O persoană interesată, aflată în pipeline, care nu este încă pacient. |
| **A1–A5 (acțiuni)** | Acțiunile succesive de comunicare dintr-o etapă (ex: A1 = primul mesaj/apel, A2 = mesaj de reamintire etc.). |
| **Exit** | Statusul cu care se închide o etapă. Poate fi **pozitiv** (lead-ul avansează) sau **negativ** (lead-ul se închide). |
| **Reprogramare** | Stabilirea unei noi programări după ce pacientul nu s-a prezentat sau a cerut o altă dată. |

## Statusuri și câmpuri în CRM

| Termen | Ce înseamnă |
| --- | --- |
| **CRM** | Sistemul în care înregistrăm contactele, etapele și statusurile. Vezi [Template CRM](/comunicare/template-crm). |
| **SALE** | Câmpul din CRM cu **suma achitată efectiv** de pacient în clinică. Se actualizează la fiecare plată. |
| **VALOARE INTEGRALĂ PLAN DE TRATAMENT** | Câmpul din CRM cu **valoarea totală** a planului de tratament propus. |
| **Prezentat / Neprezentat** | Dacă pacientul a venit sau nu la programarea stabilită. |
| **Absent** | Pacientul nu s-a prezentat și nu a putut fi reprogramat — exit negativ. |
| **Lost** | Finalul negativ al pipeline-ului (persoana nu devine pacient). Vezi motivele în [Site de comunicare](/comunicare/site-de-comunicare). |
| **Contact greșit / divers / recrutare** | Motive prin care un contact se închide fără a fi un lead real (a greșit numărul; contact intern; ne caută pentru angajare). |

## Roluri

| Termen | Ce înseamnă |
| --- | --- |
| **Patient Care (Manager)** | Persoana care preia pacientul în clinică, argumentează planul de tratament și gestionează obiecțiile. Vezi [Comunicare patient care](/comunicare/comunicare-patient-care). |
| **Responsabil Call Center / Contacte** | Persoana care contactează telefonic lead-urile pentru a obține și confirma programările. Vezi [Comunicare Call Center](/comunicare/comunicare-call-center). |
| **Recepție** | Preia pacientul la sosire și programează investigațiile / următorii pași. |

## Produse și servicii medicale

| Termen | Ce înseamnă |
| --- | --- |
| **Prima consultație** | Consultația inițială (200 MDL) care include evaluarea și planul de tratament. |
| **Consultație de specialitate** | Evaluare suplimentară necesară în anumite cazuri înainte de tratament. |
| **CBCT** | Radiografie 3D folosită pentru planificarea corectă a tratamentului. |
| **Implant** | Rădăcină artificială din titan pe care se fixează dintele. Clinica folosește Megagen AnyOne, Megagen AnyRidge și Straumann — vezi [Descriere produse](/comunicare/descriere-produse-si-servicii). |
| **All-on-4 / All-on-6** | Proteză fixă pe 4, respectiv 6 implanturi, pentru pacienți cu edentație extinsă. |
| **Proteză mobilă / pe capse / fixă** | Tipuri de lucrări protetice, de la cea detașabilă (mobilă) la cea fixată pe implanturi. |
| **Edentat / edentație** | Lipsa unuia sau a mai multor dinți (edentație totală = fără dinți). |
| **Osteointegrare** | Procesul prin care implantul se integrează în os. |
| **Testimoniale / cazuri clinice** | Materiale video/foto cu pacienți și rezultate reale, folosite pentru a câștiga încrederea. |
